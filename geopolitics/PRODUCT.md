# Przy stole
## Platform
Web: desktop i mobile, React + TypeScript + Vite, niezależne silniki JavaScript testowane w Node.
## Cel
Działający wybór i pełne lokalne rozgrywki przeciw komputerowi: Geopolitix, Remik, Poker, w tej kolejności implementacji.
## Decyzje
Użytkownik polecił przejść do realizacji wcześniejszego planu. Wybór proponowanego stosu i botów jest założeniem wykonawczym. Gry bez prawdziwych pieniędzy. Online i dodatkowe frakcje to dalsze etapy.
## Odbiorca
Osoba grająca rekreacyjnie na komputerze lub telefonie. Kliknięcia i dotyk, bez obowiązkowego drag-and-drop. Zasady i opis działania dostępne podczas gry.
## Ograniczenia
Auto/Jasny/Ciemny, zapis lokalny, brak API zewnętrznych w rozgrywce. Nazwa Geopolitix i ilustracja z obecnego projektu. Rozstrzygnięcia niepełnego PDF jawne w zasadach MVP.
